# Profile interview: complete answer kit

The data-cleaning project below uses the owner's supplied facts. All other example experiences are **fictional test data**, not the owner's qualifications. Unknown information remains unknown. This is a local acceptance exercise, not a job application.

## How to answer

Answer the current question in the chat. A single answer can contain several labelled fields; there is no need to split dates, tools or context into separate experience records. Use these labels when giving a complete answer: Title, Type, Organisation, Dates, Background, Personal responsibility, Personal actions, Team outcomes, Tools, Reflection, Public link.

The interviewer stores an internal field tag for each new answer. Education asks about qualification, institution, dates and status, never a mandatory contribution. You may skip unknown questions. Finish this experience stops questioning; when model consent is enabled and a structured experience exists, it also prepares labelled sections and a draft memory. Review and use pending suggestions before approving the final profile. The organiser's first version uses source excerpts rather than unrestricted paraphrasing. Original answers remain expandable; resume-specific wording is a later, separately reviewed step.

## Button sequence

1. Start or resume the profile conversation. Enable the model-processing consent checkbox.
2. Answer naturally, or paste one complete labelled experience from this kit. A complete labelled answer maps directly to fields; no extra generative extraction is required.
3. Click **Finish this experience**. Pending structured details can be organised directly; you do not need to adopt the raw version first. Wait for the success notice or visible failure message.
4. Expand **Review suggested details**, check the labelled sections and original sources, then click **Use these details in my draft** once. The memory is already saved as a DRAFT.
5. Click **Add another experience** and repeat for another story. Education needs only qualification, institution, dates and status.
6. Click **Finish interview & review** → **Review profile draft now** → review the exact snapshot → check the confirmation box → **Approve & save profile**.
7. In **Career memory & STAR library**, separately review and confirm memory drafts if you want them available to RAG. Saving the profile does not automatically confirm memories.
